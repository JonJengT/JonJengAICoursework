This is data from my class of a numbers 0-9. 
A photo will be titled, i_j_name.png
i is the actual number depicted in the image
j is the student's difference in style of that digit
name is a name for that student

All the data in this dataset is from my professor's original dataset of around 4200 digits.
The original data was actually a bit tricky, so I decided to clean it up here.
In the original dataset:
some images did not have numbers at all. 
Some images were rotated 90 degrees.
Some images were cut off.

In this dataset, went through very quickly most of the 4200 images and deleted the ones that I assumed a human would not be able to classify.

I also went in an rotated most of the images that were sideways.

I know I missed a couple of images, but generally this made a huge improvement.
